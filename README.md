## 🔬 数据挖掘发现（11600样本）

### ✅ 有效因子

| 因子 | 最优区间 | 涨率 | 超额收益 |
|---|---|---|---|
| RSI | **50-60** | 54.9% | +0.91% |
| 量比 | >2.5 | 63.6% | +1.42% |
| 偏离20日线 | **0-5%** | 55.2% | +0.56% |
| ATR | **4-6%** | 53.1% | +0.59% |
| 60日位置 | >97% | 52.4% | +0.54% |

### ❌ 无效/反向因子

| 因子 | 区间 | 涨率 | 超额 |
|---|---|---|---|
| RSI | <30（超卖）| 48.9% | -0.52% |
| 偏离20日线 | <-10% | 46.6% | -0.92% |
| ATR | <2%（死水）| 50.0% | -0.85% |

**核心洞察**：
```
买"温和上涨"的（RSI 50-60），不买"超跌的"（RSI<30）
追"巨量突破"（量比>2.5）
避免"离均线太远"（>15%）和"波动太小"（ATR<2%）
```

## ⚙️ 技术要点

### 数据源（全部免费公开）

| 用途 | 数据源 | 接口 |
|---|---|---|
| 全市场列表 | 新浪 | `Market_Center.getHQNodeData` |
| 实时行情 | 腾讯 | `qt.gtimg.cn/q=` |
| K线 | 新浪 | `getKLineData` |
| 指数K线 | 腾讯 | `ifzq.gtimg.cn/appstock` |

**注意**：东方财富的列表接口有反爬（需 Referer），K线接口偶发限流，已切到新浪。

### 成本模型（真实）

```python
佣金:   0.025%（双边）
印花税: 0.05%（仅卖出）
滑点:   0.15%（双边）
最低:   5元/笔
```

### 涨跌停处理

```
涨停（+9.8%以上）→ 无法买入，跳过
跌停（-9.8%以下）→ 无法卖出，跳过
```

## ⚠️ 风险与局限

```
① 胜率 48.9%，靠盈亏比（1.37）赚钱
   → 单笔亏损痛，需心理承受力

② 收益集中：中位数 +4.8%，最好 +338%
   → 选股运气影响大

③ 回测 ≠ 实盘
   → 滑点/成交/停牌可能更严重

④ 样本 195只 / 250天
   → 覆盖一个市场周期，可能过拟合

⑤ 2025-2026 小盘股活跃
   → 策略偏"活跃股"，换市场环境可能失效
```

## 🔌 实盘对接（华泰证券）

### 门槛

```
华泰 QMT/miniQMT: 日均资产 50万（连续20个交易日）
流程: 开户 → 满足资产 → 联系客户经理 → 签协议 → 开通(2-3工作日)
```

### 对接方式

```python
# 现在（模拟）
from executor_v2 import scan_and_trade
scan_and_trade()

# 实盘（需改执行层）
from xtquant import xttrader   # miniQMT SDK
# 把"模拟买卖"换成 xttrader.order_stock()
# 选股/择时/风控逻辑全部复用
```

**改动量**：约 2-3 天（只需替换下单/查询持仓接口）
